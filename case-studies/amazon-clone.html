Amazon Clone Website

A front-end study of a large e-commerce layout, focused on the header, product grid and responsive behaviour.

24 May 2024Solo project: design and development

HTML5CSS3
Open live demo All projects

Why I built it

E-commerce sites are some of the densest layouts on the web: a search-heavy header, category navigation, rows of product cards and a large footer. I recreated this style of page to practise building a complex layout out of small reusable pieces.

To be clear about its scope: this is a front-end study. It uses no real products, has no checkout and is not affiliated with Amazon.

What it does

  • A header with logo, search bar and navigation
  • A grid of product cards with image, title and price areas
  • Hover states on cards and buttons
  • A multi-column footer
  • A layout that adjusts to smaller screens

How it works

Components in HTML and CSS. A product card is built once as a block of markup with its own class names, then repeated. Changing the card style in one place updates every card.

Header with Flexbox. The logo, a search bar that stretches to fill the available space, and the navigation items sit in a single flex row.

.header {
  display: flex;
  align-items: center;
  gap: 16px;
}

.search {
  flex: 1;
}

Product grid with auto-fit. Using repeat(auto-fit, minmax(...)) lets the number of columns change by itself as the screen gets narrower, with fewer media queries.

Technical lessons

  • Dense layouts need a system. Without consistent spacing and sizing the page looks cluttered very quickly.
  • Naming matters. Clear class names made a long stylesheet easier to navigate.
  • Static is not the same as an application. Building this showed me what a real store would also need: a database, search, a cart, user accounts and secure payments.

What I would improve next

  • Load products from a JSON file or API and render them with JavaScript
  • Add a working cart using localStorage
  • Add search and category filtering
