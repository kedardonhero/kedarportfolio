SAMB Clone Website

A responsive front-end recreation of an existing business website, built to practise real-world page layout.

21 May 2024Solo project: design and development

HTML5CSS3
Open live demo All projects

Why I built it

Copying a finished design is one of the fastest ways to learn why professional layouts work. In this project I recreated the SAMB website from the screen alone: no template, no starter code, just the finished page and my own markup and styles.

This is a front-end practice project. It is not the real company's site and has no backend.

What it does

  • A full page layout: header and navigation, hero section, content sections and footer
  • A layout that adapts from desktop to phone widths
  • Consistent spacing, colours and typography reused across sections

How it works

Structure before style. I started with semantic HTML (header, nav, main, section, footer) so the page made sense without any CSS.

Flexbox and Grid for layout. Rows of items such as navigation links use Flexbox. Two-dimensional sections such as card grids use CSS Grid.

Responsive with media queries. The layout is checked at narrow widths, and breakpoints are added where the design actually breaks, for example when a three-column row needs to become one column.

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 24px;
}

@media (max-width: 768px) {
  .cards { grid-template-columns: 1fr; }
}

Technical lessons

  • Browser dev tools are a teacher. Inspecting how an existing page spaces and sizes elements taught me more than most tutorials.
  • Reuse beats repetition. Defining colours and spacing once and reusing them keeps a page consistent and easy to change.
  • Responsive design is a habit. It is much easier to check small screens throughout than to fix them at the end.
  • Recreating a design is not the same as designing. It showed me where I still needed to practise original design decisions.

What I would improve next

  • Use CSS custom properties for the colour and spacing system
  • Optimise and properly size the images
  • Improve accessibility: contrast, focus states and alt text review
