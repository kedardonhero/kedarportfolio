Rock Paper Scissors

A browser game where you play against a randomly choosing computer and keep a running score.

5 March 2024Solo project: design and development

HTMLCSSJavaScript
Open live demo All projects

Why I built it

After Tic Tac Toe I wanted a project that focused on rules and randomness. Rock Paper Scissors has only three options, which makes it a good place to practise expressing rules cleanly.

What it does

  • Choose rock, paper or scissors with a click
  • The computer picks randomly
  • The result of each round is shown
  • A running score for the player and the computer

How it works

The computer's choice. The three options sit in an array and a random index picks one.

Rules as a lookup. Each option beats exactly one other. Storing that in an object avoids a long chain of nested conditions.

const beats = { rock: "scissors", paper: "rock", scissors: "paper" };

function playRound(player, computer) {
  if (player === computer) return "draw";
  return beats[player] === computer ? "win" : "lose";
}

Updating the score. After each round the result updates a counter and the page text. Keeping the logic in playRound() separate from the display code made it easy to test with plain function calls.

Technical lessons

  • Lookup tables simplify logic. The rules fit in three lines of data instead of nine cases.
  • Separate decisions from display. A function that only returns a result is easy to test and easy to reuse.
  • Randomness needs checking. Running many rounds confirmed that the computer's choices were reasonably even.

What I would improve next

  • Add rock-paper-scissors-lizard-Spock to see how the lookup scales
  • Add a best-of-five mode
  • Add animations between rounds
