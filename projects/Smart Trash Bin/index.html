Recent fill level • dashed line = full threshold (80%)

Each sensor is converted to a percentage, smoothed with an exponential moving average, then fused. If either sensor reads 85% or more, the result is lifted so a full bin is never under-reported. If both are near empty, it stays low. Otherwise the lower reading wins. 80%+ is Full, 40%+ is Half.
